# Jack-Portfolio-Oct

> High-performance interactive portfolio for **Jack Gilbert J.** featuring parallax typography animations, floating glassmorphism navigation, dynamic skill matrices, and selected computer vision & machine learning projects.

---

## 🚀 Live Demo & Preview
- **Local Dev Server:** `http://localhost:5173/`

## 🛠️ Tech Stack & Architecture
- **Structure:** Semantic HTML5 with complete Open Graph & SEO metadata
- **Styling:** Modern Vanilla CSS3 with 8px design tokens, CSS variables, glassmorphism (`backdrop-filter`), and responsive typography (`clamp`)
- **Animations:** Hardware-accelerated Parallax scroll engine, floating pill navigation scroll spy, tab state machine with neon indicators, and IntersectionObserver scroll reveals
- **Assets:** AI-matted transparent portrait cutout (`jack_profile.png`), vector SVGs, and downloadable resume

## 📂 Project Structure
```text
├── index.html               # Main portfolio markup & semantic sections
├── style.css                # Design system tokens, parallax layers & styles
├── script.js                # Parallax scroll engine & interactive tab switching
├── jack_profile.png         # Transparent cutout portrait
└── Jack_Gilbert_Resume.pdf  # Downloadable verified resume
```
